# Open Home Hero brand pack

Everything you need to put the brand on social media, the website, print and
email. Folders:

| Folder | What is in it |
|---|---|
| `01-logo/svg` | The logo as vector files. Use these for print, signage and anything that must be sharp at any size. |
| `01-logo/png` | The same logos as transparent PNGs (2000 px wide). Use these for documents, slides and websites. |
| `02-social/profile-pictures` | Square profile pictures, sized for each platform. |
| `02-social/cover-images` | Cover and banner images for Facebook, X, LinkedIn and YouTube. |
| `02-social/sharing-and-posts` | Link-preview image, square and portrait post templates, story/reel cover. |
| `03-app-icons-and-favicon` | Website favicon, phone home-screen icons. |
| `04-brand-guide` | The rules: logo use, colours, fonts, voice. Start with `BRAND-GUIDE.md`. |
| `05-editable-svg-sources` | Editable versions of the banners and post templates (text is already converted to outlines). |

## Which file do I use?

* **Profile picture on any platform:** `02-social/profile-pictures/` and pick the platform's name.
* **Cover image:** `02-social/cover-images/` and pick the platform's name.
* **Logo on a white or cream background:** `horizontal-for-light-backgrounds`.
* **Logo on a dark or photo background:** `horizontal-for-dark-backgrounds`.
* **One-colour print (stamps, single-colour signage):** the `navy-one-colour` or `white-one-colour` files.

## Before you spend money on print or merchandise

The name **Open Home Hero** has not yet had a trade mark attorney opinion, and
no trade mark has been filed. Use the pack freely online, but hold off on
large print runs, vehicle wraps and signage until the attorney has given the
go-ahead and the trade mark application is lodged.

## Fonts

The logo's lettering is already converted to outlines, so you don't need any
font to use the logo files. For new material use Source Serif 4 and Inter
(both free from Google Fonts, SIL Open Font Licence). Licences are in
`04-brand-guide/fonts-licences`.
